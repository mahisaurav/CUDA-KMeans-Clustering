This project implements Lloyd's K-means clustering in serial C++ and CUDA C++ and compares their performance on five reproducible two-dimensional datasets ranging from 10,000 to one million points. In the CUDA implementation, each thread assigns one point to its nearest centroid. Thread blocks accumulate coordinate sums and point counts in shared memory before merging the totals, and the host uses those totals to update centroids and check convergence. Both implementations use the same starting centroids and stopping rule, and the benchmark compares median wall-clock runtime while checking labels, centroids, and inertia. The project reports transfer and allocation costs as part of the CUDA time so the comparison reflects the cost of running the clustering operation. On the Tesla T4, the packaged implementation took 9.21 ms at one million points, compared with 36.41 ms on the Colab CPU, giving a 3.95× speedup. The CPU and GPU agreed on every label across all five workloads.
